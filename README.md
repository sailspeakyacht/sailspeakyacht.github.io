# SailSpeak on GitHub Pages

Static brand page for https://sailspeak.com/

## Publish

1. New GitHub repo, public, name `sailspeak` (or a GitHub user/org named sailspeak for `sailspeak.github.io`).
2. Upload `index.html` (and this README).
3. Settings → Pages → Deploy from branch `main` / root.
4. Live URL goes into `brand/sailspeak/TRACKER.md`.
